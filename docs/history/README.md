## Read the archive offline

A full clone already has these revisions. From the repository root, for example:

```sh
git show 5f08f557ef7945667dd633c07d83291015f6e8e0:docs/reviews/2026-10-09-audit-corrections.md
```

Checkout searches omit archived text. Search the saved journals with Git:

```sh
git grep -n 'COMPLETE' 5f08f557ef7945667dd633c07d83291015f6e8e0 -- docs/reviews
```

For a shallow clone, fetch that revision once before going offline:

```sh
git fetch origin 5f08f557ef7945667dd633c07d83291015f6e8e0
```

For a source ZIP, use the pinned web links or clone the repository and fetch the
revision. Replace the revision and path to read an engine record. This reduces
the current checkout, not Git history or a full clone's historical storage.
